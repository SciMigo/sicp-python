Write `mirrored(items, left=0, right=None)`, which says whether the inclusive window `items[left]` to `items[right]` reads the same in both directions. Lists have at most 20 integers. Compare the outside pair; when it matches, the answer is whatever a recursive call says about the window inside it. A window of zero or one elements is mirrored. Do not slice, copy or change the list: pass the same list down with new boundaries. The starter draws the "enter" frame; before each call returns, call `show_window(items, left, right, "leave", answer)` with its Boolean answer.
