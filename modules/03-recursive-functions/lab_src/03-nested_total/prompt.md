Implement nested_total(node, path=()) for finite acyclic lists containing integers or more lists, with nesting depth at most 10. Integers return themselves; an empty list returns zero; other lists combine the answers from all children. Recursively visit children left to right. Append each child index to its tuple path. Call show_node(path, node, answer) once after this node is complete, including leaves and empty lists. Do not mutate input or keep an accumulator between calls.
