A route covers a distance with jumps of length 1 or 3, and the order of jumps matters. Write `route_trace(n)`, the number of routes that cover exactly `n`. A remaining distance of 0 is one finished route; a negative remaining distance is none. Otherwise a route ends with a 1-jump or a 3-jump, so add the counts for `n - 1` and `n - 3`, making the `n - 1` call first. The starter calls `show_route(n, result)` once per call, after the result is known; keep that for every call, including the ones that return 0. Before you run the demo for n = 4, predict how many calls it makes in total.
