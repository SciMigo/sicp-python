A packing line fills exactly n units using permitted batch sizes. Order matters: a small batch followed by a larger one is a different plan from the reverse. Implement `packing_plans(n, sizes, modulus)` returning the number of plans modulo a positive integer. The sizes are distinct positive integers in any order, and n is nonnegative. Zero units has one empty plan; no permitted sizes means no plan for positive n. Use `combine(a, b, modulus)` for each addition of plan counts. For n up to 6,000, use at most n times the number of sizes combine calls and avoid a deep Python call chain. Settings and counts must be fresh between calls. The starter follows valid smaller remainders but repeats work and cannot support the large request. The demo displays the residue actually returned.
