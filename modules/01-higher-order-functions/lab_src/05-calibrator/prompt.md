A sensor receives fixed adjustment records during setup. Each `(scale, offset)` record changes a reading to `scale * reading + offset`, in the supplied order. Setup must return a callable accepting later readings. Its behavior must remain fixed if the original settings list changes, and separately prepared services must stay independent. The supplied version is correct on unchanged settings but does too much arithmetic for every reading. For 240 records, setup may use at most four arithmetic operations per record; each later reading may use at most four, however many records there are. Empty settings preserve the input. Use integer arithmetic without converting the supplied numbers to plain ints or floats. The demo shows the actual input and returned reading.
