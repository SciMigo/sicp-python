This is SICP exercise 2.4's alternative procedural pair. Implement `cons(x, y)` returning a callable pair. When called with a function `choose`, that pair must call `choose(x, y)` exactly once and return its result. Preserve the original objects and keep different pairs independent. Creating a pair must not select either part. The supplied first and second selectors pass their own chooser functions; the helper draws their returned values. Predict those two values before running.
