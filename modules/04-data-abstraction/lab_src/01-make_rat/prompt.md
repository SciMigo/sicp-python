Zero must select as 0 over 1. Reject d equal to zero with `ZeroDivisionError`. Use the supplied `numer` and `denom` to observe the result. Call `show_rat(n, d, result)` once after a valid construction. The four cells show input numerator, input denominator, selected numerator and selected denominator. Predict the demo before Run.
