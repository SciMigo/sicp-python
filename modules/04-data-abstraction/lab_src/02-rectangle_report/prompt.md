SICP exercise 2.3 asks for the same area and perimeter client to work with two rectangle representations. Complete `rectangle_report(rect)` using only the supplied `width(rect)` and `height(rect)` selectors. Dimensions are nonnegative numbers. Read width once, then height once; return `(area, perimeter)`. Call `show_dimensions(w, h, area, perimeter)` once. The demo uses a callable rectangle; checks also swap in a different selector package. Do not special-case storage layouts. Predict the report first.
