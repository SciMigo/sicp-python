A dashboard configures integer panel prefixes once, then asks each panel to label readings later. Implement `prepare_badges(prefixes)` returning one callable per prefix in the original order. Calling position i with reading x must return `(original_prefix_i, x)`. Configuration may finish before any reading arrives. Later changes to the input list must not alter the prepared behavior. Duplicate prefixes are allowed, and separate setups must remain independent. Empty input returns an empty list. The supplied version creates callables but they do not keep distinct panel behavior. The demo draws the prefixes actually returned by your callbacks.
