A function value in this model is a record: `{"params": [names], "env": index}`, where `env` is the index of the frame in which the function was defined. Implement `call_frame(frames, function, arguments, caller)`, the step that happens every time a function is called.

Append one new frame to `frames`. Its bindings pair each parameter with the matching argument (the counts always match), in a dictionary of its own. Choose its parent by the rule from the lesson. `caller` is the index of the frame the call was made from; you are told it so that you can decide whether it matters. Do not change the function record, the argument list or any existing frame. Then call `show_call(frames, new_index, caller)` once and return the new frame's index. The helper draws the new frame and the chain of parents a lookup would follow from it.

In the demo, `add_rate` adds its `reading` to a free name, `rate`. It was defined in frame 0, where `rate` is 6, and it is called from frame 1, where `rate` is 80. Predict the printed result before you run it.
